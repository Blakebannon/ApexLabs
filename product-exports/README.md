# Product exports

This area contains export definitions and deliberately reviewed evidence packages for later Apex Sim Coach review. Local/generated packages belong under ignored `generated/` unless intentionally preserved.

An export is not executable configuration and must never modify production automatically. Verify it with `apex-labs verify-export`, then read its manifest, independent validation artifacts, review states, scopes, uncertainty, and caveats before considering any product work. Verification establishes integrity and internal consistency—not authorship, scientific correctness, or production approval.

`synthetic-mechanics-demo-v1` is intentionally committed as a small, deterministic contract example. It contains synthetic data only and says `do_not_implement`.
